# День Достона Хайдарова

Простая 3D HTML-игра на Three.js по сценарию:

1. Будильник → Пробел
2. Комната: шкаф (одежда), зеркало, обувь у двери
3. Гараж → езда по городу к институту
4. Аудитория → «Поспать на паре» (Пробел) → пара закончилась
5. Улица → езда к офису Билайн
6. Офис с 10 столами (двойные мониторы с «Билайн»)
7. Рабочее место → ввод «Достон Хайдаров» → Beeline Чаты

## Управление
- WASD / стрелки — ходьба / вождение
- E — взаимодействие
- Пробел — основные действия (будильник, сон на паре)

## Запуск
Откройте `index.html` в браузере.

## Город
Использован простой процедурный город. Чтобы подставить вашу модель из `.blend`:
1. Экспортируйте в Blender → File → Export → glTF (.glb)
2. Замените `buildCity()` на загрузку GLTFLoader.

Модель города (Lile de la cité tosell.blend) не была импортирована автоматически, т.к. в среде нет Blender.
